## 火效为什么返工了几轮

第08镜一度把火点在木桩上，第09镜石圈和柴堆又接不上。早期火苗在少量状态间反复切换，燃烧段显得跳动。从原画提取亮部再移动像素，又拉变形了火焰。换用独立视频素材后，火焰有了连续变化，轮廓和质感仍与底画割裂，前面几次火星也不够明显。

获批短样把原画、机位、着火点和前景木柴遮挡固定下来，用本地绘制的透明序列帧表现火星飞散、火苗长起和燃烧。尝试失败时火星迅速衰减，成功时火星接到柴草；燃烧段按原画调整轮廓、暖色与亮度。先用约 18 秒的短样听取反馈，确认后才合入正片。

合入后用户仍指出 1:38–1:39 的手部图片、光线和状态接不上。V6 把这段收成两个机位。昴在同一个手部近景里完成第四次擦击并溅出火星，随后切回地上的柴堆起火。早期曾用项目配置的外部 OpenAI API 补图，用户叫停后，火效和后续成片返修改用本地工具。后续封面按用户要求使用内置 ImageGen。

## 封面、发布素材与交付

最早两张封面沿用了章节标题和排版字，用户希望封面更有悬念，并由 ImageGen 生成文字。封面标题改成《谁在守护谁？》，延续正文里雷姆、路伊和城外送别的关系。B站和 YouTube 的发布标题采用章节名《想要守护之物》。

16:9 初版的「守」字拖了多余长尾。单改这个字又出现笔触不一致的问题。实际可用的办法是生成一张完整的题字原图，统一笔画、字重、颜色和收笔。两种比例共用这套字，分别排版并放大核对「守」。原画后来重新生成，4:3 用雷姆和路伊近景，16:9 用三人和远处的古拉尔。象牙白题字试排后，用户明确选回笔画统一的暖金色题字。

暖金题字版 ZIP 已核验，包含 1280×960 和 1280×720 的两张 PNG，以及一份含两平台标题、简介、标签和音频来源的文案。V6 视频曾通过 Wormhole 匿名解密下载并核对哈希。素材已提供下载文件。Gmail 尝试因具体收件地址的授权未获自动审批核实而被拦截，邮件未发送。
