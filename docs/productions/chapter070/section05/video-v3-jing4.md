# 第5节片尾读音修复

用户指出末句“困境”的“境”读成了一声，要求第四声 jìng。本次仅替换31镜最后一个分句，保留显示稿“昴却落入了另一个困境。”，TTS该处采用同音字“困镜”，仍使用MiMo冰糖原始音色和默认速度。

合成候选带有后续辅助句以保留完整声尾，实际只采用1.64至3.58秒的目标分句，辅助句未进入成片。在原片404.24至406.5秒内替换旁白贡献，音乐和音效保留；修补区外三份冻结WAV逐样本相同。三版均复制原有视频流，字幕与410.5秒时长不变。

独立终检在最终AAC中测到“境”的音高约194降至159Hz，支持下降调；ASR确认没有辅助句。三版视频包及时间戳与源版一致，AAC与冻结WAV片尾零偏移，真峰值均低于-2dBTP。未实际试听，不将声学检测写成听审。

采用文件、补丁边界、生成候选、终检和交付证据位于 `data/productions/chapter070/section05/video-v3-jing4/`。交付仍使用Wormhole，另在既有交付页提供小体积末句试听文件，封面与其他非视频素材沿用此前版本。
