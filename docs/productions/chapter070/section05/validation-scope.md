# 第5节成片检查范围

本片按用户确认的31镜彩色分镜制作，使用FFmpeg逐镜缓慢推进。没有产品页面、交互演示、Gallery镜头卡或Remotion工程，因此产品宣传片的页面采集、电子鼓点、卡片入场、工作台和产品收尾规则不适用。

字幕沿用本项目已确认的固定底部版式：中文Noto Sans CJK SC 64、锚点(960,948)，英文DejaVu Sans 44、y=954/1004。字号是排版参数，不能声称字芯高度为64像素；按实际画面检查清晰度、行宽、遮挡和边界。产品宣传片Q11的56像素字芯数值不作为本片硬门槛。

逐镜核对已确认PNG哈希和实际成片首中末帧，另检查完整解码、总帧数、双语字幕、片尾接续、AAC与冻结WAV同步、最终响度和真峰值。独立终检绑定主片哈希。当前工具没有实际音频感知通道，ASR和技术测量均不替代听审，报告保留actualListening:false。

首版曾使用Litterbox的72小时临时MP4直链；用户随后改选Wormhole，后续修订沿用该渠道，关闭上传端后独立下载并核对大小和SHA-256。有效期与下载次数按当次页面记录，最新文件由本节manifest.json定位。两种比例的封面、简介、字幕和不含视频的素材包通过既有分镜页提供。邮件发送沿用明确的授权范围，没有相应指令时不发送。
