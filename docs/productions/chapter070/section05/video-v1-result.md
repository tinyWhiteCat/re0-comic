# 第5节《男人很艰苦》制作结果

这是video-v1的历史制作记录，后续视频修订与片尾读音修复见video-v2-result.md及video-v3-jing4.md；当前采用版本以本节manifest.json为准。

已采用用户确认的storyboard-v6，共31镜。成片长6分51.125秒，24帧/秒；输出1080p、1080p无配乐版（保留配音与音效）及720p。冰糖默认声音，片头相同开句复用此前已确认的R、E、零读法录音。封面主标题“一个都不能丢”，4:3与16:9分别排版，PNG尺寸为1280×960和1280×720。

全部32段的96张首中末帧及116条字幕已经检查，三版完整解码成功。独立终检无必须修复项；最终主片为-19.3 LUFS、-2.2 dBTP，抽样AAC与冻结WAV偏移0ms。当前工具无法实际听音，未完成听审或正常速度连续播放，不将ASR或测量结果当作听审。

三版MP4最初均上传Litterbox，按当次API选择72小时，并通过匿名下载逐项比对SHA-256。2026-11-10用户指定Wormhole后，1080p原片已原样转存并设为交付页主链接；关闭上传页后用全新接收会话完整下载，大小及SHA-256一致，记录见 `video-v1-bingtang/wormhole-delivery.json`。Wormhole当次有效期为24小时或100次下载，以先到者为准；Litterbox保留为备用及其他版本入口。封面、视频简介和不含视频的约9.4MB素材ZIP放在既有分镜页。素材包采用便于下载的JPEG副本；成片使用已确认PNG原图。未发送邮件，也未发布到视频平台。
