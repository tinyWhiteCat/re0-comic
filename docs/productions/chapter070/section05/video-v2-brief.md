# 第5节《一个都不能丢》视频修订

以已交付的31镜成片为基线，按用户本轮反馈修改六处：片头口播标题；河水背景声；15镜托抱双臂与手的位置；跳河入水音量和质感；23镜“可她还没恢复意识”及对应英文；上岸后咳水声。

仅重录01、23两组配音，沿用冰糖原始音色与默认速度，Re:0开句复用已确认原声。仅重绘15镜，其余30张图和29组语音复用。两张封面文案已为“一个都不能丢”，继续沿用。口播、显示稿、字幕、简介、元数据和素材包统一展示标题，原著文件及原著标题保留。

15镜右臂托雷姆上背、右手接触她的上臂；左臂承托双膝后下方，逐一检查肩、肘、腕和掌的连接。伤指不包扎、不截指。保留背上路伊、十米断崖及深河，与14、16镜接续。

河水从14镜听见流水处渐入，崖边、入水、水下和岸上按空间调整。20镜采用真实跳入水中音效，较旧水花提高约12 dB的混音目标峰值；23镜配男性呛咳，24镜配女性咳嗽与短吐水层。所有声源登记来源及许可。最终响度、真峰值及AAC同步以导出实测为准；无法实际听音时如实保留听审限制。

完成独立终检后，按已确认的Wormhole渠道重新上传，并关闭上传端、用新接收会话下载核对大小与SHA-256。旧链接保留在历史记录，当前交付页切换至修订版。
