## 下一次用什么手段解决

1. **设定先过关。** 出图前打开当节人物正侧面、兵器多视图、车体和场景图，逐镜指向所用版本。做一张能看清角色、道具比例和机位的关键画面，再展开同场镜头。旧长柄与新单手斧这类冲突，在首轮图源清单就标清。
2. **把同一动作放在一起审。** 出手前、接触和结果各交代什么，逐镜写到实际台词、支点、视线和状态。横抱看上背与膝弯，架刀看两手与刃面，登车看抓栏和蹬板。单镜修完把前后两张一起打开，合稿复查新旧图并存的整段。子镜优先裁已确认画面并配动作卡，裁切无法表达关键动作时再补关键画面。
3. **短片先过从原图到最终编码的检查。** 首镜同帧对比母图、最大裁切和成片。原画少细节则重画，已有细节偏软再试超分。用包含静止和运镜片段的短样核编码参数、段首关键帧和实际播放。动作切点按成片旁白的起音与词尾，字幕从第一个镜头按底部居中设计。
4. **声画和交付都核实际输出。** 专名、品牌和多音字从最终 AAC 抽听，自动识别有疑点时看音节、基频和实际剪接。效果声按实测起音贴动作，看片确认听感。Wormhole 用匿名整文件下载和哈希核取件，Gmail 核附件与收件箱结果。封面同时看原尺寸和平台缩略图。
