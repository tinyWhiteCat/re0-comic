# 图文与成片验收

按本次修改范围使用清单，记录证据和未完成项。完整生产先交付完整分镜稿供用户确认，再制作视频、两张封面图和视频简介；审稿交付与最终交付分别记录。局部任务只检查所请求范围及受影响的衔接。只改文案时不要求重新渲染；只修一句读音时不重画全片。技术测量、看图检查与实际试听分别记录。

## 原著与解说

- [ ] 已通读目标节，记录来源文件和 SHA-256；每镜有可查找的段落锚点，必要时附行号。
- [ ] 开场、人物位置、时间关系完整，未擅自把中段冲突移到故事开头。
- [ ] 能解释关键动作的动机，以及场景间的因果。人物掌握的信息没有被全知视角误改。
- [ ] 原文的“可能”“认为”“尚不清楚”仍保留；失去意识没有改成死亡。
- [ ] 关键对白与讲述者归属正确。未经原文支持的心理描写、结局和后续人物身份没有混入。
- [ ] 前后镜台词衔接自然，次要动作没有喧宾夺主；已按 Humanizer-zh 润色。
- [ ] 逐镜稿、纯口播、字幕和配音计划指向同一版文稿。

## 每张图与相邻镜头

- [ ] 看过实际原画参考，角色发型、瞳色、发饰、服装和剧情阶段一致。
- [ ] 主体朝向、视线及表情符合当前动作，不只检查角色是否出场。
- [ ] 人物站坐躺姿、左右位置、持有物与前后镜接得上。动作反转有依据。
- [ ] 对每个人分别数手、脚、鞋和可见关节，没有重复、悬空或凭空增加的肢体。
- [ ] 能从每只手追溯到手腕、袖口、手臂、肩膀、颈部及对应的头；衣领与手掌分开。
- [ ] 交叠肢体的前后遮挡合理，肤色、袖色和人物身份没有混用。
- [ ] 握持道具的透视、手指接触、箭杆走向和身体受力成立。
- [ ] 受伤程度、环境和表情共同支持本镜情绪，没有提前画出原文尚未确认的结果。
- [ ] 字幕区和推进后的裁切不会盖住或切掉理解动作必需的部位。
- [ ] 每张原尺寸检查，并连看相邻镜头；缩略总览不能替代局部人体检查。

复杂肢体返修若局部改动仍不能解释整体连接，应重构姿态，再核对与前后镜的衔接。不要把错位解释为“只是遮挡”。

## 分镜审稿与确认

- [ ] 已提交本期全部彩色分镜图及逐镜台词，按播放顺序一一对应，注明转场和预计时长；材料可查看，不能以提示词或少量示例代替完整稿。
- [ ] 审稿记录包含版本、状态（待确认 / 需修改 / 已确认）、用户反馈、明确确认原话或消息引用、确认时间及批准范围。
- [ ] 正式配音、混音或视频渲染开始前，本期使用的图文版本和范围已获用户明确确认；沉默、等待结束或技术检查通过不算确认。
- [ ] 已确认的同版本同范围直接复用确认记录；镜头顺序、关键画面或台词含义等重大改动已对受影响内容重新确认。
- [ ] 仅读音、编码等不改变已审图文的技术修复记录了范围，可沿用原确认，无需强制重审。
- [ ] “待确认”或“需修改”阶段未启动本期正式配音、混音或视频渲染，未把审稿材料交付标记成整期制作完成。

## 配音与字幕

- [ ] 新制作显式使用 `mimo-v2.5-tts` 与冰糖预设，采用服务默认语速；顶层及每组都未传 `style`、克隆参考音频，文本没有括号语气或速度标签。对照[已确认样音](../../../../docs/voice-profiles/mimo-bingtang-default.md)检查；复现历史 A 或晓晓时明确记录范围。
- [ ] MiMo 音频已另行完成字幕对齐，没有把分组时长或按字数估算当成逐词时间。
- [ ] 普通段落没有按字幕逐句切碎；停顿扣除了相邻音频已有的静音，未叠成长空白。
- [ ] 显示稿、实际口播稿和 TTS 输入分别留档并指向同一冻结版本；读音替换、仅显示的注释及简称读法能逐项对应。
- [ ] “艾米莉娅”等姓名完整连续；“原著”的“著”为 zhù；词组读音覆盖没有污染显示稿。
- [ ] Cor Leonis 口播为“狮子心”，字幕首次出现有拉丁名注释；不把注释文字当作实际发声内容对齐。
- [ ] 简称既读对字母和数字，也符合所需的连读节奏；没有因为插入标点而变成逐字报读。静音测量只辅助定位停顿，不替代自然度判断。
- [ ] 陌生简称、连读争议或读音多次返工已用几秒短样核验。用户要求先试听，或读法、节奏仍需用户选择时，已交付短样并按所需确认进入整片；其他情况按已有授权执行，同版、同范围确认不重复询问。
- [ ] 需要确认的样音已记录源 WAV、试听 MP3、各自的路径与 SHA-256、实际文本及用户确认原话和范围；API 原音、重采样制作副本和试听编码没有混称为同一文件。
- [ ] 已确认的同一句录音经哈希核对后直接复用，没有再次合成替换成未经确认的新结果。文本、节号或声音参数变化时另行生成并检查，未套用旧音频或扩大原确认范围。
- [ ] 原声、纯人声成轨、最终混音分别检查持续噪声、爆音、削波、突兀拼接及漏字重复。
- [ ] 已用可用的音频感知能力或真人试听核对自然度；若只有数值检测，明确写“尚未试听”。
- [ ] ASR 转写、静音测量、代理实际听音和用户试听确认分别记录。历史近音误识别及“未试听”记录仍保留；后续用户确认不被改写成代理曾经听审，也不因同一已确认样音的短片段 ASR 差异反复索要确认。
- [ ] 保留冰糖默认的说话方式，未靠额外语气指令、后期移调、拉伸、均衡、降噪或压缩改变已确认声音；场景情绪与动作层次通过配乐和音效补充。
- [ ] 中文字幕与英文意思、专名、推测语气一致，出现和结束使用同一语音时序。
- [ ] 两种字幕都固定在画面下部，中文在上、英文在下；两行英文不会把中文顶上去。
- [ ] 没有专用黑色底栏，深色描边足以保证阅读；运镜不带动字幕。
- [ ] 对最长字幕、两行英文、标点和片尾附近字幕实际栅格化或抽帧检查，无遮挡、重叠、越界。

第一节 1920×1080 的排版参考：中文 Noto Sans CJK SC 64，底部中心锚点 `(960,948)`；英文 DejaVu Sans 44，第一行顶部中心 `(960,954)`，第二行 `(960,1004)`。不同分辨率按比例适配并重新检查字形边界，不能只靠字符数量判断是否放得下。

## 运镜、音乐与片尾

- [ ] 每个正文镜头都有独立焦点，起、中、末画面确有缓慢推进，非静态轮播。
- [ ] 推进不抖动、不突跳；群像关系、脸和关键接触点在终点仍清楚。
- [ ] 音乐烘托情绪且不盖住旁白；关键音效按实际动作对齐，没有每镜强塞音效。
- [ ] 音乐和音效来源及许可条件有记录，所需署名随交付保存。
- [ ] 片头口播为英文字母 R、E 加数字“零”，三个音自然连读，不逐字停顿；TTS 没有再强制用逗号隔开，显示稿仍为 Re:0。随后简短说明帝国篇原著解说、第七章及本期节号，画面给出节名，不朗读冗长中文全名。
- [ ] “未完待续”采用与普通字幕不同的 Re:0 氛围字标，无默认 JOJO 箭头或正式宋体。
- [ ] 片尾延续最后一镜最终机位和亮度，无黑闪、跳回全景或字幕压住片尾大字。

## 封面与简介

- [ ] 两张封面分别为 4:3（默认 1280×960）和 16:9（默认 1280×720），已核对实际宽高；同图的 PNG、JPG 不计作两张。
- [ ] 两种画幅分别排版，人物比例自然，标题完整，重要内容留有安全边距；没有靠拉伸或裁掉文字适配比例。
- [ ] 主标题已按用户确认稿生成，两张图均逐字检查系列名、节名、标点与残留文字，并检查人物身份和表情。
- [ ] 简介说明本期冲突与讲述范围，已对照原著和定稿，不添加后续结果、不把推测写成确定。
- [ ] 简介经 Humanizer-zh 润色，保存为可复制的文本文件，内容与交付文案一致。

## 局部修订

- [ ] 已冻结上一版及本次替换范围；新输出另存，未覆盖旧母版或把未执行的检查复制为本版通过。
- [ ] 新语音按实际采样数与成片帧率安排首尾留白和切点；全部有效源采样保留，没有为凑旧时长裁掉发音、变速或移调。
- [ ] 仅在后续正文内容、镜头时长和内部时序均未变时，才按片头帧差整体平移字幕、词边界、镜头、配乐和音效；逐项核对偏移及动作锚点。其他改动按实际音频重算受影响时序，不套用一个总偏移。
- [ ] 未改的源音、图稿和封面核对哈希；沿用的正文音轨核对对应 PCM。复用已编码的静音画面缓存前，核对源图、滤镜、帧数及编码参数，再比对缓存源与目标哈希；带字幕或音轨的缓存还须核对其是否受新时序影响。
- [ ] 检查新片段及前后交界的画面、字幕和音频接续，并检查确实受影响的正文位置；不因一句读音修复重画图稿或重复全套剧情审查。
- [ ] 最终成片仍完成一次完整解码和最终 AAC 响度、真峰值测量；共享检查结果时核对成片与日志哈希，不重复扫描同一未变文件，也不拿旧版本报告代替本版证据。

第二节的连读返工、样音确认和局部替换过程见[第二节制作经验](section02-lessons.md)。本节中的时长、停顿、帧差和镜头数量都是当次实测值，不作为后续默认值。

## 导出与交付

- [ ] 分镜审稿阶段与最终交付阶段分开记录，确认依据能追溯到实际生产使用的版本。
- [ ] 完整生产的四项核心产物齐全：视频成片、4:3 封面图、16:9 封面图、视频简介文本文件；局部任务明确标注交付范围。
- [ ] 已核对素材 ZIP 内的实际文件清单，只含封面、简介、字幕、口播稿和说明清单等非视频资料；1080p、720p、无配乐版、预览片等所有视频均单独交付。
- [ ] 视频默认上传至 [Wormhole](https://wormhole.app/)，完整上传并匿名下载核验后，在聊天中给完整链接（含 `#` 后的解密片段）、当次有效期和下载次数限制；没有发送视频或视频链接邮件，也没有把待验证的上传记为成功。
- [ ] 素材邮件仅寄往会话已授权的邮箱；发送前检查相同素材的回执，已有 API 接受记录时不因视频换平台重复寄送。
- [ ] 视频链接、素材 ZIP 和交付记录指向同一交付版本；包内字幕对应新时间线，口播稿对应采用的录音。复用未改素材有哈希依据，没有因只更新视频而留下旧字幕包。
- [ ] 当前成片或交付指针只在对应产物验收及本次所需交付完成后更新；试听、渲染中或上传未核验的版本没有被标为已交付。
- [ ] 素材邮件 API 接受回执与收件箱实际到达分别记录；没有把 API 接受或云环境下载成功扩大为用户已收到、已观看或大陆下载速度已验证。
- [ ] `ffprobe` 核对画幅、尺寸、帧率、时长、音视频流；FFmpeg 完整解码无报错。
- [ ] 检查开头、中段、结尾的声画与字幕同步。改配音后没有继续使用旧时长。
- [ ] 最终编码后重新测响度和真峰值；约 -18 LUFS、真峰值不高于 -2 dBTP，无削波。
- [ ] 图、配音、字幕、镜头和成片的路径/版本能对应；哈希记录匹配实际交付文件。
- [ ] 局部修补检查未改部分：音频尽量比对 PCM，视频流复制时比对流哈希；重新编码的画面用对应抽帧核对，不要求文件哈希相同。
- [ ] 分享页能匿名打开，下载后的文件与本地成片哈希一致；若网站打包 ZIP，核对其中目标文件。
- [ ] 记录当次有效期、提取码和预览能力。没有验证的项目不标为通过。
