# 当前默认规格

用户本轮要求优先。这里集中记录新制作使用的规格；历史数值仅用于复现，不固定新节的镜数、字幕数或时长。

| 项目 | 默认要求 |
| --- | --- |
| 图稿与故事 | 全幅独立彩色分镜，默认不烙入台词或气泡；原著顺序、开场与因果完整，人物认知/推测/生死状态准确。实际查看设定和邻镜，核对空间、朝向、表情、道具、全身比例与关节连接。保留“还没恢复意识”等状态延续及对应英文，不把暂时配合画成恢复记忆；跨镜伤势按完整状态区间检查。 |
| 审稿 | 图、逐镜台词、转场和预计时长先给用户确认；同版本同范围直接沿用批准。实质图文改动重审受影响范围，读音/编码修复不强制重审整套。返修按用户范围交付，允许只发修订页。 |
| 声线 | `mimo-v2.5-tts`、显式 `voice: 冰糖`，服务默认音高与速度；顶层和组内不传style，不加括号语气标签，不克隆参考音频。依据[已确认样音](../../../../docs/voice-profiles/mimo-bingtang-default.md)，不自动切换历史A、晓晓或CLI默认茉莉。 |
| 人声处理 | 保留API原样源。制作允许等时长采样格式转换、已验证静音处剪辑和固定增益；不加EQ、降噪、压缩、移调或时间拉伸。整轨目标约−18 LUFS，真峰不高于−2 dBTP，峰值约束优先。 |
| 读音 | 姓名连续输入；“原著”读zhù，必要时局部映射原著→原住，不能全局替换所有“著”。艾米莉娅不拆词。Cor Leonis口播狮子心，首次字幕注拉丁原词，注释不交TTS。别名仅影响口播输入，显示稿保留原字。句末重词和用户纠正的声调需检查完整声尾；“困境”为kùn jìng，第5节局部TTS别名“困镜”不改显示稿。ASR汉字不证明声调。 |
| 片头 | 显示Re:0，口播字母R、E加“零”自然连读，已确认输入 `R E零`，不插逗号逐个报读。随后简短说明帝国篇原著解说、第七章与本期节号，画面给节名，不恢复冗长中文全名。节名按用户已明确的展示标题，与实际TTS、字幕、封面、元数据、简介和包内文稿一致，原著文件不改。 |
| 字幕 | 实际音频对齐；中文上、英文下，固定叠在画面下部，不加底栏，不因换行上下跳。1080p参考：中文Noto Sans CJK SC64底部锚点(960,948)，英文DejaVu Sans44顶部y954/1004；以真实字形检查边界。 |
| 运镜与视频 | 横屏1920×1080、24fps；正文每镜按独立焦点缓慢推进，检查首中末，保持角色关系及关键手脚/武器可读。推进倍率随构图决定。 |
| 配乐音效 | 根据本节实际动作、冻结配音与时间线安排；有层次且不盖旁白。木棒、切枝、倒树等仅在实际发生时配声。音乐可随旁白衰减，来源与许可证留档。旁白、配乐、环境声和动作声分层；河水随远近/岸上/水下交接，入水按体量选材，咳水对应角色时点；水下滤波不施于旁白。 |
| 片尾 | 未完待续，冷白淡紫Re:0风格字标，区别于普通字幕；延续最后一镜最终机位与亮度，无黑闪或回全景。不恢复历史JOJO箭头/正式宋体。 |
| 封面与简介 | 主标题先review，同一获批标题分别生成4:3(1280×960)与16:9(1280×720)两种排版；PNG/JPG不算两张。人物关系为核心，简短且不编造剧情。简介保存UTF-8文本，说明本节冲突和范围，无后续剧透。原著标题、展示标题、封面主标题及其适用范围分别记录，已有明确文案不重复确认。 |
| 交付 | 完整一集交付1080p视频、两种封面、简介。素材ZIP收封面/简介/字幕/口播/说明等非视频文件，所有视频单独交付。Wormhole完整上传、关闭发送页后新匿名上下文整文件下载核验，给完整含#链接及当次期限/次数。视频与链接不邮件；仅无视频素材ZIP寄会话已授权邮箱，已有相同包API接受回执不重复发。邮箱/密钥/临时分享链接不进公开skill。用户在中国大陆下载，不使用腾讯或阿里云，不自动回退旧平台；每个视频版本单独验证，局部修音可附短试听。 |

实际试听、ASR/技术测量和用户确认分别记录；没有试听不能声称听审通过。交付成功不等于用户已观看、邮件到箱或大陆速度已验证。上传/邮件按当前授权执行，不新增惯例审批。
