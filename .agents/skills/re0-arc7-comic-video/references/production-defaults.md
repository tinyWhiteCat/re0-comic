# 当前默认规格

用户本轮要求优先。镜数、字幕数与时长按本节计划和实测确定。

| 项目 | 默认要求 |
| --- | --- |
| 图稿与故事 | 按本轮制图要求制作独立全幅彩图。默认原图无台词和气泡，字幕后期叠加。按原著顺序交代开场、因果和状态变化。 [分镜验收](quality-checklist.md#分镜) |
| 审稿 | 完整图文、转场和估时经确认后制作。复用同版同范围的批准，实质改动重审受影响部分。按用户范围可只交修订页。 [阶段依赖](execution.md#阶段依赖) |
| 声线 | `mimo-v2.5-tts`、显式 `voice: 冰糖`，服务默认音高与速度；顶层和组内不传style，不加括号语气标签，不克隆参考音频。依据[已确认样音](../../../../docs/voice-profiles/mimo-bingtang-default.md)，不自动切换历史A、晓晓或CLI默认茉莉。 |
| 人声处理 | 保留API原样源。制作允许等时长采样格式转换、已验证静音处剪辑和固定增益；不加EQ、降噪、压缩、移调或时间拉伸。整轨目标约−18 LUFS，真峰不高于−2 dBTP，峰值约束优先。 |
| 读音 | 姓名连续输入，艾米莉娅不拆词。“昴”读 mǎo，“宣布”的“宣”读 xuān，“原著”的“著”读 zhù，“九神将”“飞龙将”的“将”读 jiàng，“困境”读 kùn jìng。按完整词组核多音字，如“十米长”读 cháng，“长回一只手”读 zhǎng。必要时仅对目标词组加 TTS 别名（如“原住”“掌回一只手”“困镜”），显示稿保留原字。Cor Leonis 口播“狮子心”，首次上屏注明拉丁原词。 |
| 片头 | 显示稿和实际 TTS 输入按[片头合同](intro-contract.json)。口播英文字母 R、E 和中文“零”，按正常台词速度自然连读。本期节号与展示节名默认只上屏，用户明确要求口播时单设语义组。字标、节号和节名分级排版。 [请求与缓存检查](production-pipeline.md#片头读法与缓存检查) |
| 字幕 | 按实音对齐。片头、正文和插画的双语字幕全程固定在画面底部正中。中文在上，英文换行时中文不动，不加底栏。1080p 参考：中文 Noto Sans CJK SC 64 底锚 (960,948)，英文 DejaVu Sans 44 上锚 (960,954)/(960,1004)。遮住关键动作时调整分行、取景或运镜，核实际字形。 |
| 运镜与视频 | 横屏 1920×1080、24 fps。按镜头焦点设计方向、幅度、起终点和停留。通常缓慢推进或横移，需要保留动作、人物关系或字幕空间时稳定全幅。 [画面验收](quality-checklist.md#画面与动效) |
| 配乐音效 | 每集正式成片默认包含按剧情编排的配乐。按[场景配乐](style-reference.md#场景配乐)分段选曲，按[声音时间线](execution.md#声音时间线)确定进出点。音乐可辨，旁白优先，关键对白或转折可留白。配乐、环境声和动作声分别处理。用户要求为木棒击中、切开树枝等实际动作配声。具体场景与混音按[验收清单](quality-checklist.md#音效选材与混音)。 |
| 片尾 | 沿用已确认的「未完待续」字标（冷白裂纹字、淡紫光晕、荆棘或叶片、小号 TO BE CONTINUED），只上屏。默认延续末镜机位和亮度，待末条字幕结束后在右下角淡入。按本期获批布局与转场验收，位置和大小取实际画幅及主体。 [字标来源与放置](style-reference.md#片尾放置与抽查) |
| 封面与简介 | 默认 ZIP 恰含 `封面_4x3.png`、`封面_16x9.png`、`发布文案.txt`。用户确认封面主标题后，用 ImageGen 生成题字，两版按同一标题独立排版为 1280×960 和 1280×720。UTF-8 文案分列 B站与 YouTube 标题、简介和可复制 tags，共用简介可注明。必要署名、来源、许可链接和修改说明放简介末尾。B站格式 `【Re:0 帝国篇】{节号至少两位} {展示节名} 漫画视频`。YouTube 格式 `【Re:0 帝国篇】 原著漫画解说视频 第七章第{不补零节号}节:{展示节名}`。保留示例空格、英文冒号及分支节号标识。原著标题、展示节名、封面主标题和平台标题按各自用途登记。 |
| 交付 | 默认视频走 Wormhole，发布素材走 Gmail，按本轮明确授权调整渠道。内部图稿、音频、字幕、脚本及检查资料按明确请求和许可另附。大陆下载场景不用腾讯或阿里云。 [打包与收发](delivery-and-publishing.md) |

```text
B站视频标题：
【Re:0 帝国篇】09 帝国的作风 漫画视频

YouTube视频标题：
【Re:0 帝国篇】 原著漫画解说视频 第七章第9节:帝国的作风
```
