# 当前默认规格

用户本轮要求优先。这里集中记录新制作使用的规格；历史数值仅用于复现，不固定新节的镜数、字幕数或时长。

| 项目 | 默认要求 |
| --- | --- |
| 图稿与故事 | 全幅独立彩色分镜，默认不烙入台词或气泡；原著顺序、开场与因果完整，人物认知/推测/生死状态准确。实际查看设定和邻镜，核对空间、朝向、表情、道具、全身比例与关节连接。保留“还没恢复意识”等状态延续及对应英文，不把暂时配合画成恢复记忆；跨镜伤势按完整状态区间检查。逐镜记录原生尺寸，不用小尺寸拼图裁片冒充高清，插值不算新增细节；按当前用户指定工作流执行。 |
| 审稿 | 图、逐镜台词、转场和预计时长先给用户确认；同版本同范围直接沿用批准。实质图文改动重审受影响范围，读音/编码修复不强制重审整套。返修按用户范围交付，允许只发修订页。 |
| 声线 | `mimo-v2.5-tts`、显式 `voice: 冰糖`，服务默认音高与速度；顶层和组内不传style，不加括号语气标签，不克隆参考音频。依据[已确认样音](../../../../docs/voice-profiles/mimo-bingtang-default.md)，不自动切换历史A、晓晓或CLI默认茉莉。 |
| 人声处理 | 保留API原样源。制作允许等时长采样格式转换、已验证静音处剪辑和固定增益；不加EQ、降噪、压缩、移调或时间拉伸。整轨目标约−18 LUFS，真峰不高于−2 dBTP，峰值约束优先。 |
| 读音 | 姓名连续输入；“原著”读zhù，必要时局部映射原著→原住，不能全局替换所有“著”。长度的“十米长”读cháng，避免与后文拼成“长大”。艾米莉娅不拆词。Cor Leonis口播狮子心，首次字幕注拉丁原词，注释不交TTS。别名仅影响口播输入，显示稿保留原字。句末重词和用户纠正的声调需检查完整声尾；“困境”为kùn jìng，第5节局部TTS别名“困镜”不改显示稿。ASR汉字不证明声调。 |
| 片头 | 品牌短句的显示稿和实际TTS输入按[独立读法规则](intro-contract.json)分别登记，口播字母R、E加中文“零”，按正常台词速度自然连读，不插逗号逐个报读，不展开成“从零开始”。读音、词内速度与词间停顿分别检查，旧读音反馈不覆盖后续节奏纠正。合成或复用前运行 `scripts/check-re0-intro.ts`，另核源音与成片的真实品牌及“原著”读法；缓存绑定规则、文本、模型、声线、完整参数和音频SHA-256，声线批准不代替内容证据。本期节号与节名只上屏，展示标题与字幕、封面、元数据、简介和包内文稿一致，原著文件不改。 |
| 字幕 | 实际音频对齐；中文上、英文下，固定叠在画面下部，不加底栏，不因换行上下跳。1080p参考：中文Noto Sans CJK SC64底部锚点(960,948)，英文DejaVu Sans44顶部y954/1004；结合主体留白与真实字形确定本期统一位置，检查边界及遮挡，参考坐标不代替成品可读性。 |
| 运镜与视频 | 横屏1920×1080、24fps；正文通常按独立焦点缓慢推进，需保护关键动作、人物关系或字幕空间时可保留稳定全幅。检查首中末，保持表情、关键手脚及道具可读，推进倍率随构图决定。 |
| 配乐音效 | 根据本节实际动作、冻结配音与时间线安排；有层次且不盖旁白。木棒、切枝、倒树等仅在实际发生时配声。音乐可随旁白衰减，来源与许可证留档。旁白、配乐、环境声和动作声分层；河水随远近/岸上/水下交接，入水按体量选材，咳水对应角色时点；水下滤波不施于旁白。 |
| 片尾 | 未完待续，冷白淡紫Re:0风格字标，区别于普通字幕；延续最后一镜最终机位与亮度，无黑闪或回全景。不恢复历史JOJO箭头/正式宋体。 |
| 封面与简介 | 发布素材包含两个平台的视频标题、内容简介、两张封面和视频tags。B站标题：`【Re:0 帝国篇】{节号至少两位} {展示节名} 漫画视频`；YouTube标题：`【Re:0 帝国篇】 原著漫画解说视频 第七章第{不补零节号}节:{展示节名}`，保留所示空格与英文冒号，09对应9；分支节号保留实际标识。封面主标题与平台标题分开记录，不自动用封面短标题替换节名。主标题先review，同一获批文案分别生成4:3(1280×960)与16:9(1280×720)，PNG/JPG不算两张。简介存UTF-8文本，说明本节实际冲突和范围；B站与YouTube tags分别提供可复制列表，按本节内容去重、无后续剧透。原著标题、展示标题及适用范围分别记录，已有明确文案不重复确认。 |
| 交付 | 视频统一通过Wormhole发送，所有视频/预览片单独交付，素材统一通过Gmail发送。必备发布素材为B站视频标题、YouTube视频标题、内容简介、4:3和16:9两张封面、视频tags；其余字幕/口播/原图/说明按本次授权附入无视频素材ZIP。Wormhole完整上传、关闭发送页后新匿名上下文整文件解密下载核验，聊天给完整含#链接及当次期限/次数；视频和视频链接不通过邮件发送。Gmail沿用会话已授权收件人，核对附件与实际发送回执，草稿不算已发；相同包已有API接受回执不重复寄，工具接受不等于到箱。邮箱/密钥/临时分享链接不进公开skill。用户在中国大陆下载，不使用腾讯或阿里云，不自动回退旧平台；每个视频版本单独验证，局部修音可附短试听。 |

实际试听、ASR/技术测量和用户确认分别记录；没有试听不能声称听审通过。交付成功不等于用户已观看、邮件到箱或大陆速度已验证。上传/邮件按当前授权执行，不新增惯例审批。
