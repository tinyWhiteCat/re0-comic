# 执行与增量返修

## 阶段依赖

```text
storyboard → voice → alignment → visuals ─┐
                             → sound ───┴→ render → review ─┐
storyboard → covers ────────────────────────────────────────┴→ package → delivery
```

先完成策划（`plan`）。分镜冻结须有当前完整编号彩色图文、转场、估时和用户明确批准。此前可预览文字、构图、字幕和运镜，标明临时估时。获批后正式配音，解决实质疑点并冻结采用音后再对齐。画面、动效和混音按实音时点制作，齐备后渲染、终检。

英文翻译、选曲、音效计划和有故事与标题依据的封面可提前准备。封面冻结依赖已冻结分镜，视频可并行制作。完整交付以视频核验和素材真实发送为准。局部制作按授权范围执行，按需更新独立指针。

批量前在已授权阶段为新增或变化的风险做最小代表试样，复用同条件有效证据。全片开渲前，用成片规格试渲有疑点的镜头或片尾，连播核表情时点、运镜、裁切与编码。阶段命令、输入输出和验收证据统一登记在 `production-state.json`。见[状态工具](state-tool.md)。

## 生成前先固定约束

1. **设定与状态。** 按[分镜记录](source-fidelity.md#共享素材与逐镜状态)核角色外形和共用素材。注明入镜状态、可见变化和离镜状态，伤势、持有物、湿污、体能和认知随事件更新，一次性效果标明起止。
2. **空间与后果。** 用同一地标核侧别、距离、视线、接触和遮挡。常规参考讲不清走位、遮挡或受力时，启用[按需场景构建](#按需场景构建)（`--risk scene`）。先定比例与支撑，再做光效。换场交代时空，保留原著留白。连续动作可接实际尾帧，换机位时核来向和接点。
3. **镜头与声音。** 每镜定一项叙事任务，合并重复信息，给时空和情绪留白。交审稿用关键画面呈现表情、动作及状态变化，必要时用邻镜或自由布局的子分镜交代前后。标明顺序与触发台词或事件。自然连读估时，计入换气、反应和转场。规划焦点、方向、节奏和事件声，再核字幕安全区与接点。
4. **先验证高风险项。** 试做复杂姿态、受力、遮挡、远景身份与状态衔接。连看关键图的起势、接触、反应和结果，确认机位、站位及支撑后展开同场动作。采用图和结论写入分镜记录。

## 按需场景构建

按场景或连续动作段判断。已有参考能交代相对位置和支撑时直接出图，如固定站位的正反打。多人交错、换机位后方位不明、跨层视线、地形变化、接触或支点转移难读时，由主 Agent 启动独立场景 Agent。策划用 `plan --risk scene`，出图或返修发现问题用 `storyboard --risk scene` 补建受影响段落。

1. **场景 Agent 交付共用参考。** 对照原文、相关前文、设定和采用镜。用俯视线框或简模标地标、朝向、机位、视线、路线和落点。高度差或遮挡需要时补侧视或剖面，地形变化标受损和通行范围。连续动作通常用两三幅草图标接触前后、支点、受力、持物手及道具落点。悬吊画明从固定点到身体的承重链，投射画明轨迹与接点，握持难辨时附同角度局部参考。分别记原文依据、画面选择与信息揭示时点。
2. **主 Agent 核准并交接。** 对照原著顺序与前后采用镜核地标、视线和动作后果，登记采用草图、参考图路径和适用镜号。相关镜头共用核准版，其他场景可同步推进。草图内部核对，完整分镜按现有范围交用户确认。
3. **分镜 Agent 用同一份参考选机位。** 沿固定地标核换机位后的人物距离、朝向和遮挡。站位或支点有变时，主 Agent 先核对并同步场景图。合稿实看动作全过程及跨机位、跨段接点。

露台接点看第 25 节，远望、兵器转移和手部接触看第 27 节。场景图可先画出支点，成片依原著和口播依次揭示。 [第 25 节跨镜复盘](../../../../docs/productions/chapter070/section25/retrospective.md#分镜与跨镜连续性) · [第 27 节分镜与握姿复盘](../../../../docs/productions/chapter070/section27/retrospective.md)

## 生成提示词

提示词写景别、机位、光线、站位、动作、表情和参考图用途。用“从柜台这一侧拍，窗边的人在左，门口的人在右，两人对望”落实轴线。静态图写选定瞬间，动态图另写动作起止、运镜和结束姿态。考据和检查结果留在制作记录。

连续分镜返修逐镜记原文锚点、站位、支点、反应、参考图、确认母图和邻镜，注明改动、保留项和候选退回原因。上下文压缩、换会话或中断后按记录重开原文与实图。先修关键画面，再接前后的姿势和持有物。

局部问题从最新确认母图编辑，保住握法、承重和视角。穿插、接点或透视错误先定机位、支点和遮挡，再重画。候选退化则回母图，同一错误复现则调整参考、机位或动作拆分。采用前按[分镜验收](quality-checklist.md#分镜)并排实看。

## 长分镜的分段制作

1. **主 Agent 先统一整节。** 核原著顺序和镜号，共用一份设定和采用清单。按镜号引用角色、服装、道具、场景、风格、已通过的关键图与核准场景图。
2. **子 Agent 按场景或完整动作段分工。** 每镜一位负责者，起势、接触和结果同属一人。跨段延续的状态先定进出条件。后段依赖上段实图时等其确定，独立段落并行。
3. **交接指向本期文件。** 列镜号、原文锚点、口播、参考、前后接点和产出目录。接点含站位、视线、伤势、持有物、动作阶段和地标。各段交候选图、台词和未通过项，共用设定变更由主 Agent 核对后同步。
4. **主 Agent 统一实看和合稿。** 动作段成组看，跨段看前一段末镜和后一段首镜。核轴线、动作后果、情绪和道具状态，按出场镜号复查共用设定。核整稿编号、台词与采用版本，更新清单和阶段状态，按原批准范围交审。

## 声音时间线

在声音计划记录配乐的叙事用途、进出锚点、淡入淡出、停顿、旁白下声量和来源。关键台词或转折可只留旁白、环境声或静默。环境声随空间交接，动作声记录画面或旁白锚点与素材实际起音。正式混音按冻结旁白的对齐结果落点。

## 外部模型与成片来源

用户指定外部模型时，先用最小请求分别验证所需能力，如图像生成或编辑、运镜规划、视频生成。分别核环境有无密钥、模型能否列出、指定接口是否实际输出。阶段记录写采用模型、接口、产物与验证状态，凭据留在环境配置中。

指定能力不可用时说明受影响环节和可继续范围。交付按实际链路说明来源，如第 14 节外部模型生成分镜与运镜方案、本地合成成片、封面后改用 ImageGen。

## 有限语音返修

1. 先用一套 ASR 筛查句首、专名、漏句和长停顿。以批准文稿列出每一处易错词，在采用音轨定位，结合相邻词核音节和变调。遇同音替字、儿化省略或单模型插入先查实际声音，实质疑点补听辨或声学证据并记范围。
2. 每组最多两次额外合成。先用同输入生成独立候选，仍是句首问题则把前文末句带入当前完整语义段，在实测静音处裁回，保留完整首音、API 原音、切点和 PCM 相等证据。词组读音与句末声调同样计入上限。
3. 到上限停止自动付费重试，保留最佳候选和阻塞原因，按已有授权局部改写或交短样请用户判断。保持已批准含义，实质问题解决后才进入正式合成。
4. 按实际口播和请求复用录音，批准绑定源音及范围。节号或标题只上屏时只更新画面。口播变化时在已验证静音处保留获批前缀，合成变化的后文。

补录沿用既定声线和语速，在静音处接回完整词组或短句，从最终 AAC 核目标发音、声尾、辅助句已剪净及接缝。读音别名仅用于对应词组的 TTS 输入。调整口播标点时核实际停顿，保持词组自然连读。只修多余停顿时确认窗内无有效语音，保留两侧音节采样。时长变化按[变更影响](#变更影响)重新对齐。 [精确裁接参考](production-pipeline.md#句末声调与旁白补丁) · [第 17 节读音与停顿案例](../../../../docs/productions/chapter070/section17/retrospective.md#专名读音与句内停顿)

转写字形正确时仍要核多音字声调，按识别时点对照相邻音节的基频变化。单套转写或音高阈值只作技术证据。局部替换可用同声线、读法和语境相近的已核录音。惊讶复述核音节数、实际停顿和完整声尾，停顿计入素材自带无声。等采样数替换后仍核旁白起止、字幕、镜尾留白和音效锚点。 [第 25 节配音与剪点](../../../../docs/productions/chapter070/section25/retrospective.md#配音字幕与动作剪点) · [第 26 节配音案例](../../../../docs/productions/chapter070/section26/retrospective.md#配音与字幕)

## 变更影响

先确认问题在哪一环，按实际影响定修改和验证范围。共享设定查全部出场，持续状态查连续区间，单镜查本镜及邻镜。共用合成、运镜或序列读取问题，先查使用该方式的镜头，再查受影响的编码与接点。沿用已通过的语义、构图、音色和可复用时序。

在现有 brief 或问题记录写明现象、依据、范围、目标、保留项和采用基线，已有信息只引路径。图像返修按[生成提示词](#生成提示词)从清晰母图着手，逐轮对照人物、衣纹、光线和环境。修后用原图或原音复核改动、保留项和所属段落。判断复用范围时纳入邻镜、全局时点及转场、字幕和音效依赖。重审按实质改动和已有批准范围判断。

定位后再重试，语音付费尝试沿用上述上限。未解决的实质问题登记为本阶段阻塞。

| 变更 | 重做范围 |
| --- | --- |
| 图稿、焦点或画面效果 | 重做受影响片段和字幕缓存，核前后接点。时序与声音未变可复用原音轨和其余画面，核最终编码包哈希及时间戳。 |
| 读音补丁，原句窗口与非目标锚点不变 | 仅替换两侧安全静音之间的旁白，更新逐词边界，核未改 PCM、同步及最终 AAC。超窗按一组录音处理。 |
| 等时长断句调整 | 按新音修正停顿、分句归属、窗口内逐词边界、字幕和音效锚点，保留窗外时序，核两端接点。 |
| 一组录音 | 重做本组对齐、停留时间、底片和镜内字幕，更新后续全局起点、音效锚点、混音及封装。复用其余组原音和相对时序。 |
| 翻译/字幕样式 | 重做对应字幕视频和最终视频，复核变化的字形与布局。 |
| 仅片头/片尾图层，音轨与时间轴未变 | 只重渲对应片段，其余片段与整条 AAC 优先直接复制。核采用资产与布局、邻镜机位和亮度接点、编码包、时间戳及有效时长。字节一致以实测为准。 |
| 音乐/音效 | 对应声部、混音与封装，复用已烧字幕视频流。 |
| 发布标题/tags/封面/简介 | 只更新相应文稿或资产、素材包及必要的 Gmail 素材邮件。片中展示标题也有变时，按实际影响更新画面。 |
| 链接过期 | 重传同一文件并核验，不重生成媒体或重复寄相同素材。 |

复用先核内容、参数和实际文件哈希。逐镜缓存键绑定源图、裁切、相机、帧数、编码、镜内字幕、动效来源、遮罩、透明度、锚点及相关邻镜接点。混音缓存键绑定旁白、声音资产与事件时间。阶段工具检测已登记依赖的失效。

## 证据复用与交接

检查结论绑定输入哈希，详证留本地，其他记录引路径。脚本查格式、边界与哈希，模型查原著、图义与翻译。注明对象、版本、覆盖范围和方法，区分原尺寸、抽帧、连续观看、完整播放、实际试听和技术检测。转写不等于听感，抽查只覆盖所查对象。遗留问题写明位置、影响和处理状态。

实质疑点追加第二种证据。独立复核集中一次，先核既有证据适用性，再补实看和变更项。用户反馈新问题时重开对应检查，既定检查通过且无新疑点时继续下一阶段。

每镜、语音组或渲染单元完成即存源文件、实际请求与参数（不含凭据）、采用版本、输出哈希和检查状态。可复用配置与难以重建的依赖放持久目录，临时目录只放可重建缓存。

中断、超时或句柄失效后先查实际文件、进程及请求与响应，再续做。完成以产物能解码、语音完整、帧数或时长吻合、交付实际收到等对应证据为准。复用已确认的产物，付费请求结果不明先查已有证据。按证据记录并补做未完成项。见[当前阶段清单](quality-checklist.md)和[上传与核验](delivery-and-publishing.md#上传与核验)。

主 Agent 维护生产状态。长分镜按[分段制作](#长分镜的分段制作)，其余阶段按独立工作分派。交接记本期标识、阶段、变化组、阻塞和路径。冻结目录只读，返修写新版本。

优先复用工具配置入口，章节目录存配置与产物。缺的功能如实标注。短暂等封面沿用原交付流程，只有用户要求先发视频时才局部交付。记录可得的 token、TTS 重试、耗时和缓存命中，缺值写 `null`。

迁移前解析输出、缓存、日志和记录路径，断言仅写本轮目录，基线只读。核绝对路径、root 拼接和默认配置，从本期计划读取镜数、语音组数、镜号格式、章节与标题，校验实际接口。旧工具有硬编码先适配并验证。服务原音和归一化采用音分开记哈希。图像、相机、帧数、叠加及镜内字幕完全相同的已烧字片段可复用，全局 ASS 哈希变化时仍按镜判断。
