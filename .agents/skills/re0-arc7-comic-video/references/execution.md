# 执行与增量返修

## 阶段依赖

```text
storyboard → voice → alignment → visuals ─┐
                             → sound ───┴→ render → review ─┐
storyboard → covers ────────────────────────────────────────┴→ package → delivery
```

配音检查、实质疑点处理和源音冻结完成后，才启动正式对齐、底片、混音和渲染。英文翻译、选曲、音效事件计划和获批封面可提前准备。封面等待不阻塞视频制作，完整交付必须等[默认规格](production-defaults.md)中的视频与发布素材齐全，并完成Wormhole视频核验及Gmail素材发送。

批量制作前，仅为本期新增或变化的风险选择最小代表镜头/语音组验证，例如复杂接触或遮挡、关键道具、专名与情绪转折、最长字幕。已有同内容、参数和条件的有效证据直接复用，不例行重做全套小样或重复索取同范围批准。小样限于当前已授权阶段；分镜确认前可做不含正式配音的文字、构图和计划运镜布局预览，临时估时与诊断产物标明用途，正式字幕时序仍等待冻结源音对齐。

主执行者维护唯一`production-state.json`；阶段命令、输入输出和检查证据都登记在此。已有记录先check，需要执行时run，人工检查后freeze；命令退出0不自动等于质量通过。首次配置/报错才读[工具说明](state-tool.md)。工具只管依赖和哈希，制作脚本仍须有正确接口，不直接运行旧节硬编码程序。

## 生成前先固定约束

以下方法用于各集制作，具体形制、伤势、机位和声音时点由本节依据决定。信息写进已有设定引用、分镜状态与创作决策，不再另建一套重复清单。

1. **共享设定与当前状态分开管理。** 同一角色、道具、标志与场景使用同一适用版本，实际查看参考图；外形和身份作为本段固定依据，伤势、血迹、持有物、湿污、行动能力与认知按事件更新。每镜接续前镜状态，状态改变须有剧情或用户依据；离开画面不等于状态重置。远景减少细节时保留身份特征。
2. **先建立关系，再选择镜头。** 用人物身体和场景确定侧别、距离、道具归属、接触与遮挡；换机位改变这些关系的投影。画面左侧不固定等于角色左侧，镜头推进也不应无依据地改变人物间距。先看整体比例、支撑、受力和空间是否成立，再处理纹理、光效等细节。
3. **让动作留下连续后果。** 串起动作发生前、接触或命中、可见结果和后续状态。受伤、破损、沾湿、物件落地或换手后，相关后果在合理范围内延续；展示服从原文和机位，不为证明状态存在而强行暴露伤处或补造动作。
4. **把演出目标变成可观察的变化。** 每镜先确定主要事件、观众应看懂的关系和注意重点；将压迫、虚弱、警惕等目标落到尺度参照、姿态、表情、遮挡、光影与声音层次。选择符合叙事的手段，兼顾相邻镜的变化，避免仅重复形容词或不断增加特效。
5. **先验证最容易失败的关系，再扩大制作。** 从计划镜头中选转身、复杂受力、多人遮挡、远景身份或状态交接等高风险部分先试做，实际看结果后再批量生成。相机、字幕和混音有疑点时先做最小试片；按既有授权与分镜批准范围继续，不把内部试做变成额外的用户确认流程。

## 有限语音返修

1. 一套ASR筛查句首、专名、漏句和长停顿；只对实质疑点短片段使用第二种证据。同音替字、儿化省略、单模型插入不直接触发重录；实际试听能力与范围如实记录。
2. 每组最多两次额外合成：一次同输入独立候选；仍是句首问题则前文末句+完整当前段连续合成，从实测静音裁出。保留完整API源、切点及PCM相等证据，不裁首音。
3. 达到上限停止自动付费重试；保留最佳候选与阻塞原因，按已有授权局部改写，或交付短样请用户判断。不得为ASR一致无限换同音字、偷偷改已批准含义，或带未解决实质问题进入正式合成。
4. 先核对已批准录音能否直接复用；新节号不能套旧整句，已验证静音处可复用获批前缀并合成新后文。批准只覆盖实际源录音与范围。

句末声调疑点也计入上述有限重试。先检查完整声尾；必要时加入辅助后句合成，在实测静音处只取目标分句，最终检查辅助句已移除。读音别名仅限具体词组，不改变显示稿，不以单一ASR或音高阈值当听审。精确裁接、声部替换与哈希方法仅在需要实施补丁时查[旧脚本参考](production-pipeline.md#句末声调与旁白补丁)。

## 变更影响

先定位问题发生在设定/生成、识别、对齐、合成或交付哪一环，再决定修改对象和验证范围。共享设定问题检查所有相关出场，持续状态问题检查对应连续区间，单镜问题检查本镜及邻镜接点；修复保留已通过的语义、构图、音色与未受影响的时序，按下表更新依赖。

返修前在现有brief或问题记录中写清现象、依据、范围、目标、保留项和采用基线，已有信息只引用路径。图像编辑优先用清晰且已确认的母图，逐轮对照人物、衣纹、光线和环境；发生退化就回到清晰母图处理。复杂姿态先确定空间关系再出图。

返修后同时核对目标修复与保留项，拿原图或原音对照；目标正确而人物、道具、背景或时序被误改的候选仍需处理。转场、字幕和音效可能依赖邻镜或全局时间，不能只凭本镜源文件未变判断复用范围。局部修订完成后检查邻镜及所属段落的叙事连续性，是否重新交用户确认仍按实质改动和已有批准范围判断，不增加例行批准。

原样重复生成不能代替定位，语音付费尝试沿用上述上限；未解决的实质问题保留为该阶段阻塞，不用通过标签掩盖。

| 变更 | 重做范围 |
| --- | --- |
| 图稿/焦点 | 对应镜底片、字幕视频缓存和最终视频；复用未变音源。 |
| 读音补丁，语义/时间轴未变且原窗口容纳得下 | 仅替换安全静音之间的对应旁白贡献，保留音乐/音效、各版视频流和字幕；更新逐词边界，核对未改PCM与最终AAC。超窗则按一组录音处理。 |
| 一组录音 | 本组对齐、停留时间、底片/镜内字幕，后续全局起点、音效锚点和混音/封装；其他组原音与相对时序不重算。 |
| 翻译/字幕样式 | 对应字幕视频和最终视频；只重查变化的字形/布局。 |
| 音乐/音效 | 对应声部、混音与封装，复用已烧字幕视频流。 |
| 发布标题/tags/封面/简介 | 对应文稿或资产、素材包与必要Gmail素材邮件；仅发布字段变化不重渲视频，另改片中展示标题时再按实际影响更新。 |
| 链接过期 | 重传同一文件并核验，不重生成媒体或重复寄相同素材。 |

复用先核对内容、参数和实际文件哈希，文件名或`cached`标签不能代替验证。逐镜缓存键绑定源图、裁切/相机、帧数、编码和镜内相对字幕文本/时间/样式；混音键绑定旁白、声音资产与事件时间。只用镜号或全局起点作键不可靠。阶段工具检测失效，不代替逐镜缓存引擎。

## 证据复用与交接

一份输入哈希对应一份检查结论，详细结果留本地，其他记录只引用路径。脚本查格式/边界/哈希，模型查原著/图义/翻译；实际试听按可用能力记录，ASR与技术测量不扩大成听感结论。只对实质疑点追加第二种证据；独立复核集中一次，核对证据适用性后只补实际看图与变更项，不重复同文件全扫。用户反馈暴露新问题则重开对应检查，既定检查通过且无新疑点时继续下一阶段。

注明检查对象、版本、覆盖范围和方法，区分原尺寸查看、抽帧、连续观看、完整播放、音频试听与纯技术检测。抽查不扩大为全片通过；遮挡等遗留问题写明位置、影响和处理状态，不能用通过标签隐藏。

每镜、完整语音组或独立渲染单元完成后及时落盘源文件、实际请求/参数（不含凭据）、采用版本、输出哈希及检查状态。可复用配置和难以重建的运行依赖放在持久工作目录；临时目录只放可重建缓存。

中断、超时或终端句柄失效后，先核对实际文件、进程与可得的请求/响应记录，再决定续做范围。响应码、进度条与命令状态均不能单独代表产物完成：按本阶段需要检查可解码性、语音完整性、预期帧数/时长或真实接收结果。已确认完成的产物继续复用；结果不明确的付费请求先查现有证据，记录未完成项，不猜测中断根因或直接整批重做。实际产物验收按[当前阶段清单](quality-checklist.md)，交付按[上传与核验](delivery-and-publishing.md#上传与核验)执行。

默认一个执行者维护状态，不按岗位各开Agent；有明确并行授权时只拆独立工作。交接仅传本期标识、阶段、变化组、阻塞项和路径，不复制会话/全套技能/长哈希列表。冻结目录不允许后台改文件。

优先复用工具配置入口，章节目录只存配置与产物；缺失功能如实标注，不宣称全自动。短暂等待封面不另写交付分支，只有用户要求先发视频时做局部交付。按可获得的统计记录token、TTS重试、耗时和缓存命中，缺失值写null，不估造节省比例。

迁移脚本先解析输出、缓存、日志和记录路径，断言只写本轮明确目录；基线只读。镜数、语音组数、镜号格式、章节与标题优先从本期计划读取，并校验实际接口；绝对路径、root与相对路径拼接、默认配置都须检查，不凭全文替换目录名直接执行。若旧工具仍有硬编码，先适配并验证，不宣称已有通用配置能力。服务原始音频与归一化采用音频分开记哈希。相机、图像、帧数、叠加及镜内字幕完全相同的已烧字片段可复用，不因全局ASS哈希改变而全片重渲。
