# 执行与增量返修

## 阶段依赖

```text
storyboard → voice → alignment → visuals ─┐
                             → sound ───┴→ render → review ─┐
storyboard → covers ────────────────────────────────────────┴→ package → delivery
```

配音检查、实质疑点处理和源音冻结完成后，才启动正式对齐、底片、混音和渲染。英文翻译、选曲、音效事件计划和获批封面可提前准备；只有明确需要试片或技术诊断时做最小样片，诊断产物不冒充正式下游输入。封面等待不阻塞视频制作，完整交付必须等四项产物齐全。

主执行者维护唯一`production-state.json`；阶段命令、输入输出和检查证据都登记在此。已有记录先check，需要执行时run，人工检查后freeze；命令退出0不自动等于质量通过。首次配置/报错才读[工具说明](state-tool.md)。工具只管依赖和哈希，制作脚本仍须有正确接口，不直接运行旧节硬编码程序。

## 有限语音返修

1. 一套ASR筛查句首、专名、漏句和长停顿；只对实质疑点短片段使用第二种证据。同音替字、儿化省略、单模型插入不直接触发重录；实际试听能力与范围如实记录。
2. 每组最多两次额外合成：一次同输入独立候选；仍是句首问题则前文末句+完整当前段连续合成，从实测静音裁出。保留完整API源、切点及PCM相等证据，不裁首音。
3. 达到上限停止自动付费重试；保留最佳候选与阻塞原因，按已有授权局部改写，或交付短样请用户判断。不得为ASR一致无限换同音字、偷偷改已批准含义，或带未解决实质问题进入正式合成。
4. 先核对已批准录音能否直接复用；新节号不能套旧整句，已验证静音处可复用获批前缀并合成新后文。批准只覆盖实际源录音与范围。

句末声调疑点也计入上述有限重试。先检查完整声尾；必要时加入辅助后句合成，在实测静音处只取目标分句，最终检查辅助句已移除。读音别名仅限具体词组，不改变显示稿，不以单一ASR或音高阈值当听审。精确裁接、声部替换与哈希方法仅在需要实施补丁时查[旧脚本参考](production-pipeline.md#句末声调与旁白补丁)。

## 变更影响

| 变更 | 重做范围 |
| --- | --- |
| 图稿/焦点 | 对应镜底片、字幕视频缓存和最终视频；复用未变音源。 |
| 读音补丁，语义/时间轴未变且原窗口容纳得下 | 仅替换安全静音之间的对应旁白贡献，保留音乐/音效、各版视频流和字幕；更新逐词边界，核对未改PCM与最终AAC。超窗则按一组录音处理。 |
| 一组录音 | 本组对齐、停留时间、底片/镜内字幕，后续全局起点、音效锚点和混音/封装；其他组原音与相对时序不重算。 |
| 翻译/字幕样式 | 对应字幕视频和最终视频；只重查变化的字形/布局。 |
| 音乐/音效 | 对应声部、混音与封装，复用已烧字幕视频流。 |
| 封面/简介 | 对应资产、素材包与必要素材邮件，不重渲视频。 |
| 链接过期 | 重传同一文件并核验，不重生成媒体或重复寄相同素材。 |

逐镜缓存键绑定源图、裁切/相机、帧数、编码和镜内相对字幕文本/时间/样式；混音键绑定旁白、声音资产与事件时间。只用镜号或全局起点作键不可靠。阶段工具检测失效，不代替逐镜缓存引擎。

## 证据复用与交接

一份输入哈希对应一份检查结论，详细结果留本地，其他记录只引用路径。脚本查格式/边界/哈希，模型查原著/图义/翻译；独立复核集中一次，核对证据适用性后只补实际看图与变更项，不重复同文件全扫。用户反馈暴露新问题则重开对应检查。

默认一个执行者维护状态，不按岗位各开Agent；有明确并行授权时只拆独立工作。交接仅传本期标识、阶段、变化组、阻塞项和路径，不复制会话/全套技能/长哈希列表。冻结目录不允许后台改文件。

优先复用工具配置入口，章节目录只存配置与产物；缺失功能如实标注，不宣称全自动。短暂等待封面不另写交付分支，只有用户要求先发视频时做局部交付。按可获得的统计记录token、TTS重试、耗时和缓存命中，缺失值写null，不估造节省比例。

迁移脚本先解析输出、缓存、日志和记录路径，断言只写本轮明确目录；基线只读。绝对路径、root与相对路径拼接、默认配置都须检查，不凭全文替换目录名直接执行。服务原始音频与归一化采用音频分开记哈希。相机、图像、帧数、叠加及镜内字幕完全相同的已烧字片段可复用，不因全局ASS哈希改变而全片重渲。
