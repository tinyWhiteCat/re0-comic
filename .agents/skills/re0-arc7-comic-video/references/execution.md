# 执行与增量返修

## 阶段依赖

```text
storyboard → voice → alignment → visuals ─┐
                             → sound ───┴→ render → review ─┐
storyboard → covers ────────────────────────────────────────┴→ package → delivery
```

策划（`plan`）先于上图各阶段。分镜冻结须有当前完整编号彩色图文、转场、估时和用户明确批准。此前可预览文字、构图、预计字幕和计划运镜；临时估时标明用途。批准后正式配音，核完实质疑点并冻结采用音，再作正式对齐；按对齐时间制作画面、动效和混音，两者齐备后渲染、终检。

英文翻译、选曲和音效事件计划可提前准备。封面可按已有标题与故事依据先准备，封面冻结依赖已冻结分镜；视频制作可并行推进。完整交付待视频核验及素材真实发送。只做视频、封面或短样时，以授权范围完成对应工作并按需更新独立指针。

批量前只为新增或变化的风险做最小代表试样，例如复杂动作、专名、最长字幕或新特效。试样限于已授权阶段，同条件有效证据直接复用。全片开渲前，用成片规格试渲有疑点的镜头或片尾，连播核表情时点、运镜、裁切与编码细节。唯一 `production-state.json` 登记阶段命令、输入输出和验收证据。见[状态工具](state-tool.md)。

## 生成前先固定约束

1. **设定与状态。** 按[分镜记录](source-fidelity.md#共享素材与逐镜状态)查看共用素材与出场镜号。外形身份保持一致，伤势、持有物、湿污、体能与认知随事件更新，出画延续。怪物换姿势或处于远景时保留结构与识别特征，一次性效果标明起止。
2. **空间与后果。** 逐镜记入镜状态、可见变化和离镜状态，用同一地标核侧别、距离、视线、接触和遮挡。常规参考无法交代跨镜的走位、遮挡或受力时，启用[按需场景构建](#按需场景构建)（`--risk scene`）。稳定站位用场景参考或座位草图。先核比例与支撑，再做光效。施法和投射核触发、路径与落点。换场交代时空位置，保留原著留白。连续动态片段可用实际尾帧承接，换机位时核视线、来向和动作接点。
3. **镜头与声音。** 为每镜定一项叙事任务。重复表达同一信息的镜头可合并，交代时空或承接情绪可留白。成片要呈现的表情、动作或状态变化，先在交审分镜中用关键画面展示变化前后；转折、接触或结果需要交代时，补入邻镜或自由布局的子分镜。标明顺序及触发变化的台词或事件。按自然语速连读正式文稿，把换气、反应和转场计入估时；正式时点按实音与动作对齐。规划相机焦点、方向、节奏与事件声，再核字幕安全区和接点。
4. **先验证高风险项。** 试做转身、复杂受力、多人遮挡、远景身份和状态衔接。用关键图连看起势、接触、反应和结果，核机位、站位、接触和支撑，通过后再展开同场动作。采用图与结论存入分镜记录，内部试样沿用已有授权。

## 按需场景构建

按场景或连续动作段判断。常规参考足以交代相对位置与支撑的段落，直接走常规分镜，例如固定站位的正反打、同一侧递物。常规参考无法说清跨镜空间关系时，主 Agent 启动独立场景 Agent。典型情况包括多人交错走位、换机位后难以辨认相对位置，以及悬吊、坠落、支点转移或地形变化影响后续动作。策划时用 `plan --risk scene` 读取本节。若出图或返修时才发现问题，用 `storyboard --risk scene` 补建相关段落。

1. **场景 Agent 交付共用参考。** 打开原文、角色和道具设定，以及相关的采用前镜。画一张俯视简图，标固定地标、人物朝向、起点、移动路径和落点。高度差、悬吊或上下层遮挡影响动作时，再加侧视图。按动作顺序记录入镜、变化和离镜状态，标清接触对象、持物手、支点及其转移。悬吊沿固定点、受力物、承重手臂和身体核受力。分别记录原文依据、画面选择与观众何时得知这些信息。
2. **主 Agent 核准并交接。** 用原著事件顺序和已有的前后采用镜核场景图。把采用版路径和适用镜号发给各分镜 Agent，相关镜头等参考核准再出图，其他场景可同步推进。场景图可用草图或简模，以能看清站位、接触和受力为准。
3. **分镜 Agent 用同一份参考选机位。** 画面左右随机位变化，沿固定地标核人物距离、朝向和前后关系。需要调整站位或支点时，先由主 Agent 核对并同步场景图，再改受影响镜头。合稿时成组实看起势、接触、反应和结果，复核跨机位和跨段接点。

第 25 节露台段可以先标出拱口、旧裂缝和窗帘固定点，再交代越火、踩塌、失去落点与抓帘。场景图提前记支点，分镜仍按原著和口播安排何时揭示。[第 25 节跨镜复盘](../../../../docs/productions/chapter070/section25/retrospective.md#分镜与跨镜连续性)

## 生成提示词

提示词写明景别、机位、光线、站位、可见动作、表情和参考图用途。把“保持轴线”写成“从柜台这一侧拍，窗边的人在左，门口的人在右，两人对望”。静态图写选定瞬间，动态图再写动作起止、运镜和结束姿态。考据、批注和检查结果留在制作记录。

连续分镜返修逐镜记原文锚点、站位与支点、人物反应、实际参考图、确认母图及邻镜，并注明改动、保留项和候选退回原因。上下文压缩、换会话或中断后，按记录重开原文和实图。先校正关键画面，再接前后姿势和持有物。

柄长、颜色等局部问题从最新确认的母图编辑，保住握法、承重和视角。身体穿插、接触点或透视错误，先定机位、支点和遮挡，再重画相关人物或动作。候选有退化就回到母图。同一错误再次出现时，先查候选并调整参考、机位或动作拆分，再出图。采用前按[分镜验收](quality-checklist.md#分镜)并排实看。

## 长分镜的分段制作

1. **主 Agent 先统一整节。** 核原著事件顺序和镜号，确定共同的角色、服装、兵器、场景和风格参考。各段共用一份采用清单，按镜号看适用的参考图和已通过的关键画面。启用了场景构建的段落还要共用核准的场景图。
2. **子 Agent 按场景或完整动作段分工。** 每镜指定一位负责者，相对独立的段落可并行。起势、接触和结果交给同一执行者。跨段共用车辆、姿势或连续伤势时，先约定入镜与离镜状态。后段需要上段通过的实图时，等该图确定再生成受影响的镜头，其余独立工作可先做。
3. **交接指向本期文件。** 给每段列负责的镜号、原文锚点、口播、共同参考、前后接点和产出目录。接点说明人物站位、视线、伤势、持有物、动作阶段和必要的场景地标。各段在各自目录提交候选图、对应台词和未通过项。发现共同设定需要变更时，提交主 Agent 核对后再同步相关段落。
4. **主 Agent 统一实看和合稿。** 同一动作段成组并排看，跨段再核上一段末镜和下一段首镜。查轴线、动作后果、情绪和道具状态。按出场镜号复查跨段共用设定，再核整稿的编号、台词和采用版本。主 Agent 更新采用清单和阶段状态，按原有批准范围交审。

## 声音时间线

在现有声音计划或时间线中记录各段配乐的叙事用途、进出锚点、淡入淡出或停顿、旁白下的声量和素材来源。可在关键台词或转折处只留旁白、环境声或静默。环境声按空间交接，同步音效记录画面或旁白锚点与素材实际起音。正式混音按冻结旁白对齐后的时间线落点。

## 外部模型与成片来源

用户指定外部模型时，先用最小请求验证本次需要的能力，分别检查图像生成或编辑、运镜规划、视频生成。环境里有密钥、模型可列出和指定接口实际出图是不同的检查结果。记录每阶段实际采用的模型、接口类型、产物与验证状态，密钥留在环境配置中。

交付按实际链路说明来源。第14节分镜图和运镜方案分别调用了外部 OpenAI 模型，成片由本地工具合成。封面后来按用户要求改用 ImageGen。某项指定能力不可用时，先说明该项及能继续的范围，替代链路的产出按实际来源记录。

## 有限语音返修

1. 一套 ASR 筛查句首、专名、漏句和长停顿。易错专名以批准文稿列出每一处，再对应实际采用音轨，定位漏读、错读或停顿。结合相邻词核韵母、声调和自然变调，实质疑点补听辨或声学证据。记录实际试听范围；同音替字、儿化省略和单模型插入先查实际声音。
2. 每组最多两次额外合成：一次同输入独立候选；仍是句首问题则前文末句+完整当前段连续合成，从实测静音裁出。保留完整API源、切点及PCM相等证据，不裁首音。
3. 达到上限停止自动付费重试；保留最佳候选与阻塞原因，按已有授权局部改写，或交付短样请用户判断。不得为ASR一致无限换同音字、偷偷改已批准含义，或带未解决实质问题进入正式合成。
4. 按实际口播与请求复用已验证录音。品牌口播相同时，节号或标题只上屏的变化更新画面即可。确有口播变化时，在已验证静音处沿用获批前缀，合成需要更新的后文。批准绑定实际源录音与范围。

词组读音或句末声调疑点也计入上述有限重试。优先用既定声线和语速补录完整词组或短句，在实测停顿处接回，从成片听辨目标词与接缝。先检查完整声尾。必要时加入辅助后句合成，在实测静音处只取目标分句，最终检查辅助句已移除。读音别名仅用于对应词组的 TTS 输入。调整口播标点时核实际停顿，保持词组自然连读。读音已确认、疑点只在多余停顿时，可在确认无有效语音的静音窗剪接，保留两侧音节采样。时长变化后按[变更影响](#变更影响)重新对齐。单一 ASR 或音高阈值只作技术证据。[精确裁接参考](production-pipeline.md#句末声调与旁白补丁) · [第 17 节读音与停顿案例](../../../../docs/productions/chapter070/section17/retrospective.md#专名读音与句内停顿)

转写字形正确时也要查多音字的声调。用识别时点定位，比较目标音节有声部分与相邻音节的基频走向。第 26 节「昴倒觉得」的「倒」读 dào，「眯了眯眼」的两个「眯」读 mī，「九神将」的「将」读 jiàng。第 24 镜另有一处「帝国的一将」，核对为去声后沿用该句的原始采样。

同一称谓反复出现时，从实际采用音轨逐处定位，区分应修的发音和语境中的自然变调。局部替换可以先找同一声线、读法和语境相近的已核录音。第 25 节六处“公主”只替换句末读平的一处，在原停顿内接回自然三声，再从最终 AAC 复核完整尾音和接缝。[第 25 节配音与剪点](../../../../docs/productions/chapter070/section25/retrospective.md#配音字幕与动作剪点)

遇到「姐……姐姐？」这样的惊讶复述，核对实际音节数、两段发声之间的停顿和完整问句尾音。第 26 节从同一声线的两段短样分别取「姐」和「姐姐？」，在实测静音处接合。剪接后重新量两段发声间隔，把录音自带的无声算进去，再用转写和基频核对三个音节及末字的上抬。替换前后采样数相同也可能改变旁白起止，复查字幕边界、镜尾留白与后续音效时标。[第 26 节配音案例](../../../../docs/productions/chapter070/section26/retrospective.md#配音与字幕)

## 变更影响

先定位问题发生在设定/生成、识别、对齐、合成或交付哪一环，再决定修改对象和验证范围。共享设定问题检查所有相关出场，持续状态问题检查对应连续区间，单镜问题检查本镜及邻镜接点。由同一种合成、运镜或序列读取方式引起的问题，先排查使用该方式的镜头，再按实际影响回查编码与接点。修复沿用已通过的语义、构图、音色及可复用时序，按下表更新依赖。

返修前在现有brief或问题记录中写清现象、依据、范围、目标、保留项和采用基线，已有信息只引用路径。图像编辑优先用清晰且已确认的母图，逐轮对照人物、衣纹、光线和环境；发生退化就回到清晰母图处理。复杂姿态先确定空间关系再出图。

返修后同时核对目标修复与保留项，拿原图或原音对照；目标正确而人物、道具、背景或时序被误改的候选仍需处理。转场、字幕和音效可能依赖邻镜或全局时间，不能只凭本镜源文件未变判断复用范围。局部修订完成后检查邻镜及所属段落的叙事连续性，是否重新交用户确认仍按实质改动和已有批准范围判断，不增加例行批准。

原样重复生成不能代替定位，语音付费尝试沿用上述上限；未解决的实质问题保留为该阶段阻塞，不用通过标签掩盖。

| 变更 | 重做范围 |
| --- | --- |
| 图稿、焦点或画面效果 | 重做受影响片段及相关字幕缓存，复核前后接点。时序和声音未变时可复用原音轨及其余画面，并核最终编码的包哈希和时间戳。 |
| 读音补丁，原句窗口与非目标锚点不变 | 仅替换两侧安全静音之间的旁白，更新逐词边界，核未改 PCM、同步及最终 AAC。超窗按一组录音处理。 |
| 等时长断句调整 | 修正目标词两侧停顿和分句归属。以新音更新窗口内逐词边界、受影响字幕和音效锚点，保留窗口外时序并复核两端接点。 |
| 一组录音 | 本组对齐、停留时间、底片/镜内字幕，后续全局起点、音效锚点和混音/封装；其他组原音与相对时序不重算。 |
| 翻译/字幕样式 | 对应字幕视频和最终视频；只重查变化的字形/布局。 |
| 仅片头/片尾图层，音轨与时间轴未变 | 只重渲对应片段，其余片段与整条AAC优先直接复制；核已确认资产/布局、相邻机位和亮度接点，以及实际packet、时间戳和有效时长。不能因封装命令有copy就宣称字节未变。 |
| 音乐/音效 | 对应声部、混音与封装，复用已烧字幕视频流。 |
| 发布标题/tags/封面/简介 | 对应文稿或资产、素材包与必要Gmail素材邮件；仅发布字段变化不重渲视频，另改片中展示标题时再按实际影响更新。 |
| 链接过期 | 重传同一文件并核验，不重生成媒体或重复寄相同素材。 |

复用先核对内容、参数和实际文件哈希。逐镜键绑定源图、裁切/相机、帧数、编码、镜内字幕，以及动效来源、遮罩、透明度、锚点和所依赖的邻镜接点；混音键绑定旁白、声音资产与事件时间。阶段工具负责检测已登记依赖的失效。

## 证据复用与交接

一份输入哈希对应一份检查结论，详细结果留本地，其他记录只引用路径。脚本查格式/边界/哈希，模型查原著/图义/翻译；实际试听按可用能力记录，ASR与技术测量不扩大成听感结论。只对实质疑点追加第二种证据；独立复核集中一次，核对证据适用性后只补实际看图与变更项，不重复同文件全扫。用户反馈暴露新问题则重开对应检查，既定检查通过且无新疑点时继续下一阶段。

注明检查对象、版本、覆盖范围和方法，区分原尺寸查看、抽帧、连续观看、完整播放、音频试听与纯技术检测。抽查不扩大为全片通过；遮挡等遗留问题写明位置、影响和处理状态，不能用通过标签隐藏。

每镜、完整语音组或独立渲染单元完成后及时落盘源文件、实际请求/参数（不含凭据）、采用版本、输出哈希及检查状态。可复用配置和难以重建的运行依赖放在持久工作目录；临时目录只放可重建缓存。

中断、超时或终端句柄失效后，先核对实际文件、进程与可得的请求/响应记录，再决定续做范围。响应码、进度条与命令状态均不能单独代表产物完成：按本阶段需要检查可解码性、语音完整性、预期帧数/时长或真实接收结果。已确认完成的产物继续复用；结果不明确的付费请求先查现有证据，记录未完成项，不猜测中断根因或直接整批重做。实际产物验收按[当前阶段清单](quality-checklist.md)，交付按[上传与核验](delivery-and-publishing.md#上传与核验)执行。

生产状态由主 Agent 统一维护。长分镜并行按[分段制作](#长分镜的分段制作)组织，其他阶段从可独立的工作分派。交接记录本期标识、阶段、变化组、阻塞项和有关路径。冻结目录只读，返修写新版本。

优先复用工具配置入口，章节目录只存配置与产物；缺失功能如实标注，不宣称全自动。短暂等待封面不另写交付分支，只有用户要求先发视频时做局部交付。按可获得的统计记录token、TTS重试、耗时和缓存命中，缺失值写null，不估造节省比例。

迁移脚本先解析输出、缓存、日志和记录路径，断言只写本轮明确目录；基线只读。镜数、语音组数、镜号格式、章节与标题优先从本期计划读取，并校验实际接口；绝对路径、root与相对路径拼接、默认配置都须检查，不凭全文替换目录名直接执行。若旧工具仍有硬编码，先适配并验证，不宣称已有通用配置能力。服务原始音频与归一化采用音频分开记哈希。相机、图像、帧数、叠加及镜内字幕完全相同的已烧字片段可复用，不因全局ASS哈希改变而全片重渲。
