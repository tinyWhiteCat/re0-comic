# 本节制作记录

这是供 Agent 填写的制作模板，不是运行时 JSON 配置。完整生产分为“分镜审稿”和“确认后制作”两个阶段：先提交完整分镜稿，用户明确确认后再开始本期正式配音、混音或视频渲染，最终交付视频、两张封面图和视频简介。局部任务只执行用户请求的范围。未执行项写“未执行”，不能预填“通过”；审稿材料交付不等于完整生产完成。

## 分镜审稿与确认

审稿材料应覆盖本期全部镜头，按播放顺序配对彩色分镜图和逐镜台词，并注明转场及每镜预计时长。交付可查看的完整图稿和文稿，不以提示词、少量示例或未完成图代替。

- 审稿版本与材料路径/链接：
- 彩色分镜图清单及对应镜号：
- 逐镜台词、播放顺序、转场与预计时长：
- 审稿状态：待确认 / 需修改 / 已确认
- 用户反馈及待修改范围：
- 用户明确确认原话或消息引用：
- 确认时间（含时区）：
- 批准的版本、镜号/内容范围：
- 本期生产版本是否与获批版本一致：
- 是否复用已有确认及依据：

状态为“待确认”或“需修改”时，不能开始本期正式配音、混音或视频渲染。已确认的同一版本和范围可直接沿用确认；镜头顺序、关键画面或台词含义等重大图文改动须把受影响内容重新提交确认。仅修正读音、编码等不改变已审图文的技术问题，不强制重审，但须记录改动范围并核对未改内容。
