# 本节制作记录

这是供 Agent 填写的制作模板，不是运行时 JSON 配置。完整生产分为“分镜审稿”和“确认后制作”两个阶段：先提交完整分镜稿，用户明确确认后再开始本期正式配音、混音或视频渲染，最终交付视频、两张封面图和视频简介。局部任务只执行用户请求的范围。未执行项写“未执行”，不能预填“通过”；审稿材料交付不等于完整生产完成。

## 分镜审稿与确认

审稿材料应覆盖本期全部镜头，按播放顺序配对彩色分镜图和逐镜台词，并注明转场及每镜预计时长。交付可查看的完整图稿和文稿，不以提示词、少量示例或未完成图代替。

- 审稿版本与材料路径/链接：
- 彩色分镜图清单及对应镜号：
- 逐镜台词、播放顺序、转场与预计时长：
- 审稿状态：待确认 / 需修改 / 已确认
- 用户反馈及待修改范围：
- 用户明确确认原话或消息引用：
- 确认时间（含时区）：
- 批准的版本、镜号/内容范围：
- 本期生产版本是否与获批版本一致：
- 是否复用已有确认及依据：

状态为“待确认”或“需修改”时，不能开始本期正式配音、混音或视频渲染。已确认的同一版本和范围可直接沿用确认；镜头顺序、关键画面或台词含义等重大图文改动须把受影响内容重新提交确认。仅修正读音、编码等不改变已审图文的技术问题，不强制重审，但须记录改动范围并核对未改内容。

### 短样试听与确认记录

遇到陌生简称、连读争议或读音多次返工时，先用覆盖问题的几秒音频核验。用户要求先试听，或读法、节奏仍需用户选择时，交付短样并按本轮所需确认进入整片；其他情况按已有授权执行。同版、同范围已有确认时直接沿用，不新增重复审批。以下项目按实际填写，不适用时说明原因。

- 本轮试听的触发原因、问题与最小覆盖范围：
- 样音文本、模型、声音参数与时长：
- API 原音、制作 WAV 和试听 MP3 的路径、采样格式与各自 SHA-256：
- 提供给用户的试听文件及私有交付记录路径：
- 用户反馈、明确确认原话或消息引用、时间（含时区）：
- 批准的样音版本、文本与使用范围；是否复用已有确认及依据：
- 生产使用的源 WAV 及哈希；与已确认样音是否一致：
- ASR 与静音测量证据、近音差异及其判断限制：
- 代理是否实际听音、实际范围；用户是否试听确认、确认范围：
- 历史技术报告、后续确认记录各自保存位置：

同一句已确认录音核对哈希后直接复用。文本、节号或声音参数变化时，不套用旧音频，也不将原确认扩大到新录音；按本轮授权生成和检查。历史 ASR 或“未试听”记录保持原样，后续确认单独登记。用户确认源样音不等于已经听过最终混音。

## 局部修订与复用

只在局部任务中填写；新节不要套用旧节的时长、镜头数、帧差或停顿长度。方法参考[第二节制作经验](../references/section02-lessons.md)。

- 原版本、冻结记录与本次替换范围：
- 新输出目录及旧母版保留位置：
- 采用的源音及 SHA-256，是否直接复用用户已确认录音：
- 源音采样数、采样率、首尾留白、固定增益及全部源采样保留的核验：
- 原片段与新片段的起止帧、采样切点；帧差和时间差：
- 可整体平移的正文范围及依据（内容、时长、内部时序是否都未变）：
- 字幕、词边界、镜头、配乐和音效的偏移核对；动作锚点检查：
- 有实质变化的片段及重新对齐结果：
- 未改源音、图稿与封面的哈希；正文 PCM 比对范围和结果：
- 复用视频缓存的源/目标哈希及源图、滤镜、帧数、编码参数核对：
- 新片段、前后交界及其他受影响位置的抽帧/音频检查证据：
- 本版完整解码与最终 AAC 响度、真峰值报告；绑定的成片及日志哈希：
- 本轮未重复检查的部分及沿用依据、尚未验证的内容：

只有未变正文才能按单一帧差整体平移；其他改动按实际音频重算受影响时序。局部修复按影响范围检查，未改素材按来源与哈希复用；同一成片已有可核验的完整解码和 AAC 扫描结果时，不重复执行。
